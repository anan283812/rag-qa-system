## 一、代码体系说明

CAT 故障码 = MID - CID - FMI（三段式）：
- **MID**（Module Identifier）：哪个控制器报的故障
  - MID 036：发动机 ECM；MID 039：机器控制器；MID 081：变速箱控制器；MID 121：虚拟服务工具
  - （320C 老体系）69：发动机和泵控制器；6A：工具控制器；1E：监控系统
- **CID**（Component Identifier）：哪个部件/电路出问题
  - CID 0001-0006：1-6 缸喷油器电磁阀；CID 0041：8V 直流电源；CID 0042：喷油器促动控制阀；CID 0091：油门位置信号；CID 0094：燃油压力传感器；CID 0100：机油压力传感器；CID 0110：冷却液温度传感器；CID 0164：喷油器促动压力；CID 0164 喷油促动压力传感器；CID 1785：进气歧管压力传感器
  - （320C）96：燃油油位传感器；110：冷却液温度传感器；167：交流发电机；168：供电电压；190：转速传感器；248：数据自动传输器；374：转盘制动电磁阀；376：行车警报器；581：动力换挡压力比例减压阀；586：发动机转速旋钮；587：调速器制动器反馈传感器；598：行驶速度电磁阀；600：液压油温度传感器；1161/1162：泵输出压力传感器 1/2；1525：直驶电磁阀；2002：故障警报器
- **FMI**（Failure Mode Identifier）：怎么坏的
  - 00 数据有效但高于正常范围；01 数据有效但低于正常范围；02 信号错误/不稳定；03 电压高于正常（对电源短路）；04 电压低于正常（对地短路）；05 电流低于正常/断路；06 电流高于正常/对地短路；07 机械系统响应不正常（卡滞）；08 信号异常（频率/脉冲/周期）；09 异常更新率；10 异常变化率；11 故障模式不能识别；12 设备或部件损坏；13 校准失败

- 事件码（Event Code，EID）：环境/机械类事件，如 17 冷却液过热、43 蓄电池充电异常（电压低）、50 充电异常（电压高）、59 冷却液液位低、95 燃油滤堵、100 机油压力低、119 燃油油位低、171 机油油位低、179 充电异常、232 油水分离器排水要求、235 液压油位低、236 液压油滤堵、237 过载警告、272 空滤堵塞、600 液压油过热、862 专用滤清器堵塞、863 自动涂油故障。

## 五、诊断要点（FAQ）

- Active code（当前故障）与 Logged code（历史记录）区别：Active 是正在发生，Logged 是历史记录。
- 断电瓶不能清除 CAT 故障码：ECM 非易失存储，故障物理修复后 Active 码才消失。
- "Limp/Derate 模式"：ECM 检测到严重故障（如水温 FMI 00）时限制转速和液压速度保护机器。
- 排查框架：先查电瓶电压（低电压会触发幽灵码）→ 检查接头（振动松动、绿色腐蚀）→ 先看 FMI（03/04 是电气，01/07 偏机械）→ 与机械表读数交叉验证。
- 常见"难启动"相关：P0087 轨压过低、P0093 泄漏、SCV 阀（吸入控制阀）卡滞、喷油器磨损回油量大（8000-10000 小时后高发）。
