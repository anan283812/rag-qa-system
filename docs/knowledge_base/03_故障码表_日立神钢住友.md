# 日立 / 神钢 / 住友 挖掘机故障码

> ⚠️ **品牌约束（重要）**：本文件同时含日立、神钢、住友三家资料，**必须按品牌区分，严禁互相套用**：
> - 日立（Hitachi）：带 E 前缀的 E 系列预警码（如 **E03=水温过高**、E05=空气滤清器堵塞）与 ZX 五位数传感器码属日立体系；
> - 神钢（Kobelco）：SK 系列用 A/B/C/D/E/F 自诊断码与发动机 P 码；
> - 住友（Sumitomo）：7xxx 数字码。
> 用户问"日立 E03"时指日立的 E 系列预警码（水温过高），与"ZX200 纯数字码 03（A/D 转换异常）"是**两回事**，不要混淆；更不得套用小松 E03（电气系统）的含义。

## 一、日立（Hitachi）

### 日立 E 系列通用预警码【日立专用：E03=水温过高、E05=空滤堵塞】
| 代码 | 含义 | 说明 |
|---|---|---|
| E01 | 发动机油压低或油温高 | 机油系统故障 |
| E02 | 液压油温度过高 | 散热不良或长时间高负荷 |
| E03 | 水温过高 | 冷却液不足、散热器堵塞或水泵故障 |
| E04 | 冷却液液位低 / 油滤堵塞 | 需添加冷却液或更换滤芯 |
| E05 | 空气滤清器堵塞 | 进气不足、功率下降 |
| E06 | 燃油滤/油水分离器堵塞 | 供油不畅 |
| E09 | 液压马达温度过高 | 马达过载或散热不良 |
| E10 | 液压驱动器/电气系统故障 | 泵控制系统或电池线路 |
| E12 | 冷却液温度过高 | 需立即停机检查 |
| E19 | 油门执行器回路故障 | 油门电机或控制线路异常 |
| E23 | 水温传感器故障 | 断路/短路 |

### ZX200 监控器纯数字码 03（注意：此"03"不带 E 前缀，与 E03 水温过高不是同一个码）
- 故障描述：A/D 转换异常（ECM 监测异常）。
- 症状：警告灯亮、降功率模式、高温报警、温度显示与实际不符。
- 排查：测传感器电阻对比标准值 → 检查线束与接插件 → 查 ECU 与冷却系统。

## 三、住友（Sumitomo）

### 主机电气输入码（7000-7199）
| 代码 | 部件/故障 |
|---|---|
| 7000-7003 | 电源短路类 |
| 7004 | 过载压力传感器电源短路 |
| 7020/7021/7022 | 上部机体/回转/行走压力传感器电源短路 |
| 7023 | 小臂关闭压力传感器 |
| 7040 | 燃油油位传感器开路/短路 |
| 7041 | 油温传感器开路/短路 |
| 7060-7062 | 大臂/小臂/偏差角度传感器（起重机/防干扰配置） |
| 7005/7006 | 底部/压力连杆传感器（起重机配置） |

传感器判定阈值：GND 短路/开路 ≤0.25V；正常 0.25-4.75V；电源短路 ≥4.75V。

### 电气输出码（7200-7399）
- 7200 回转制动电磁阀；7201 行走高速电磁阀；7202 升压电磁阀；7204 节能电磁阀；7205 备用回油电磁阀；7206 回转开放电磁阀；7207 风扇反转电磁阀；7211 门锁杆电磁阀；7240-7243 泵功率/泵流量/风扇/大臂比例阀——开路或短路。
- 判定：输出监视器输出 ≠ 输出。

### 机械/状态码（7400-7499）
- 7421 冷却液液位过低；7422 发动机机油压力过低（启动 30s 后 ≤40kPa）；7423 空气滤清器堵塞（启动 10s 后真空开关动作）；7424 燃油滤清器堵塞。

### 通信码（7600+）
- 7600 CAN 总线异常；7601 监视器通信收发异常。

### 发动机系统 4 位码（SH210-5 等）
- 0087 燃油泵无泵送压力/泄漏；0088/0089 共轨压力异常；0090 SCV 驱动断路/+B 短路/GND 短路；0107/0108 大气压力传感器电压低/高；0112/0113 增压前进气温度传感器低/高；0117/0118 冷却液温度传感器低/高；0182/0183 燃油温度传感器低/高；0192/0193 共轨压力传感器低/高；0201-0204 喷油嘴 1-4 驱动断路；0219 超速；0237/0238 增压后进气压力传感器低/高；0335/0336 曲轴位置传感器无信号/信号异常；0340/0341 凸轮轴位置传感器无信号/异常；0380 预热继电器异常；0487/0488 EGR 位置传感器/EGR 阀控制异常；0522/0523 油压传感器异常；0601 ROM 异常；0603 EEPROM 异常；0606 CPU 异常；0611/0612 充电回路异常；1173 过热；1625 主继电器异常；2104 CAN 总线异常；2106 CAN 超时故障。

### 住友故障码 2106（铁甲网解释）
- 表示液压系统过载保护触发：油温过高、液压泵故障（叶片磨损/内部堵塞）、阀门卡滞、液压缸密封件磨损等。建议停机送修。
