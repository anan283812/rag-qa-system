## 建议的知识切分方式（供 Demo 参考）

- 故障码类：按 `品牌 + 机型 + 故障码` 建立三元组索引，一条码一行，适合做结构化检索。
- 问答类：按 Q/A 对切分，每个案例含「现象 → 排查步骤 → 结论」。
- 保养类：按「小时数节点 + 保养项目」做表格结构化。

## 已覆盖范围

- 故障码体系：小松 E 码、卡特 MID/CID/FMI、日立 Dr.ZX 五位码、神钢 A~R 码 + P 码、住友 7xxx/0xxx 码、斗山 V/E 码、沃尔沃 MID-PID-FMI、徐工 A/E 码、三一 SPN/FMI、通用 J1939。
- 维修手册：日立、小松、卡特、神钢、住友等中文维修手册丛书 + 英文 O&M/Service Manual 资源站。
- 常见故障：全车无力、热车慢、憋车、启动困难、冒烟、水温高、液压内泄等高频问题。
- 保养：10h/50h/250h/500h/1000h/2000h/3000h 周期表、卡特 C9 专项、配件库存清单。
