### DX225LC-9C 典型码详解（示例）
- **E520601-12**：ECM 电源电路检测到低电压（一般 <9V）。症状：启动困难、运转中熄火、降转速至 1500-1800、仪表读数波动。排查：电瓶负载测试（500A 下应保持 >9.6V）、充电电压 13.8-14.4V、接地线清洁、ECM 电源继电器、线束磨损点。
- **VSP013-03**：变量泵（VSP）控制系统 ECU 与泵排量控制电磁阀通信异常/信号异常。症状：全车液压无力、复合动作差、油耗升高。排查：DMS 软件读码 → 线束/接头 → 电磁阀电阻（典型 8-15Ω）→ 液压油污染检查 → ECU 复位测试。
- **VS5004-04**：车速传感器（VSS）电路信号异常。症状：无法高速行走、自动怠速失效、速度显示异常。排查：传感器电阻（典型 800-1200Ω）、气隙 0.5-1.5mm、动态信号 0.5-5V AC。
- **E000734-12**：动臂阀 2 电磁阀电流低于正常/断路。症状：动臂失控或迟缓。排查：线圈电阻 3-8Ω、线束通断、对地压降 <0.2V。

## 二、沃尔沃（Volvo）

### 代码体系
- **MID**：128 发动机 E-ECU；187 车辆 V-ECU；130 变速箱 T-ECU；249 Body Builder 模块。
- **PID/SID/PPID**：PID 100 机油压力；PID 102 进气歧管压力（增压）；PID 110 冷却液温度；SID 1/2/3/4 缸 1-4 喷油器。
- **FMI**：00 数据有效但超上限；03 电压过高（断路/对高短接）；04 电压过低（对地短路）；07 机械系统不响应（部件卡滞）。

### 常见代码表
| 代码 | 部件 | 常见含义 |
|---|---|---|
| 128-PID 100-01 | 机油压力 | 临界低油压，立即停机 |
| 128-PID 158-04 | 蓄电池电压 | 电压过低，查发电机与接地 |
| 187-PPID 1121-12 | V-ECU 电源 | 车辆控制器内部电源故障 |
| 128-SID 231-09 | J1939 CAN 链路 | ECM 与 V-ECU 通信错误 |
| 128-PID 102-02 | 增压压力 | 增压值波动，查漏气或传感器 |
| 140PSID2169（EC210B） | CAN 数据链路（MID187） | 信息显示屏数据链路通信错误 |

### 诊断要点
- 琥珀色警告 = 非关键故障；红色停车灯 = 关键故障立即停机。
- 不少"幽灵码"由电源不稳引起，先查电瓶总开关与 V-ECU 供电。
- EC 系列线束易磨损位置：气门室盖附近、液压泵侧。
- 可在显示器服务菜单清除历史错误（部分机型密码 0000 或 1234），Active 码必须修复故障后才会消失。
- "乌龟模式"（Tortoise Mode）= 发动机降额保护。
