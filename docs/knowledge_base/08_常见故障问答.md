## Q1：挖机所有动作都慢、全车没劲，是什么原因？

**答**：若所有动作均匀地慢且无力，优先检查三项（成本低、操作简单）：
1. **先导压力**是否达标（典型标准 3.5-4.1MPa，测压口一般在液压泵后方或先导歧管上）；偏低先换先导滤芯，再查先导溢流阀是否卡滞；
2. **主溢流阀**是否卡滞导致系统压力上不去（实测主溢流压力对比标准，如徐工 150D 约 27MPa）；
3. **吸油滤网**是否堵塞导致主泵吸油不足。
口诀："一压二阀三油四泵"。不要一上来就拆主泵。

## Q2：冷车正常、热车动作变慢无力，什么故障？

**答**："冷车快、热车慢"典型指向**液压系统内泄或先导压力故障**。冷车油粘度高，磨损间隙被油膜暂时填充；热车油变稀内泄加剧。常见原因：主泵柱塞/配流盘磨损、先导泵磨损、液压油变质超期未换。真实案例：徐工 150D（6100 小时）整机无力热车加剧——先导滤芯油泥→清洗后压力略升；主溢流阀轻微拉伤→清洗后 24MPa 仍不达标；拆回油滤芯见铜粉→判定配流盘磨损，大修主泵解决。

## Q3：动作慢 + 发动机掉转速严重（憋车），怎么排查？

**答**：说明发动机动力不足或液压功率匹配失衡。先查发动机：柴油滤芯堵塞、空气滤芯过脏；发动机正常则查**主泵调节器卡滞**（泵排量过大超出发动机功率）。正流量系统常见**极限功率比例电磁阀阀芯卡滞**。液压泵功率大于发动机功率即出现闷车，处理：液压泵上试验台把功率降至发动机功率的 95%。

## Q4：刚保养换完液压油还是无力？

**答**：重点查液压滤芯和吸油滤网——换油时旧滤芯未同步更换被脏油堵死；油箱底部吸油滤网长期未清洗；或新加液压油牌号不对。

## Q5：动作慢但仪表没有故障码，从哪里下手？

**答**：无故障码≠无故障。进监控模式看实时数据：先导压力、主泵压力、发动机转速、比例电磁阀电流。先导压力低于 35 公斤先换先导滤芯；主泵压力低于标准查主溢流阀；发动机转速达不到目标值查燃油/进气系统。

## Q6：动作慢 + 液压油温很高？

**答**：高度怀疑**内泄**：内泄产生热量，泄漏导致流量不足。常见：主泵柱塞/配流盘磨损、主溢流阀卡在微开位、液压油太脏。拆回油滤芯看金属粉末，有则必须拆检主泵。

## Q7：整机无动作（发动机正常，操作手柄无反应）？

**答**（以 XE900D 为例）：先查液压油位；中控查系统压力，异常用压力表逐一测：
1. P1、P2 泵+风扇泵+先导泵均无压 → 查分动器（磨损打齿/轴承损坏）或发动机连接器（故障率更高，无异响基本判定连接器损坏）；
2. P1/P2 泵无压或过低 → 查工作回路安全阀（弹簧变软/断裂导致泄压回流），再查主泵本身；
3. 无先导压力或过低 → 查先导回路安全阀、先导泵；
4. 先导锁打不开也会全车无动作；严重漏油同样导致压力低。

## Q8：行走跑偏 + 一只手柄动作不理想？

**答**：双泵有一只故障。简单判定：把液压泵两根高压油管对调，原来慢的变快、快的变慢即证实。处理：拆泵加工或更换故障泵内配件，上试验台调试。

## Q9：液压缸自动沉降（斗杆停放缓慢下落）？

**答**：密封件老化（O 型圈、防尘圈磨损）导致内漏或外漏；活塞环磨损或缸筒划伤导致保压失败。处理：换同规格密封件；拆解打磨轻微划伤，严重换活塞组件或缸筒。判定技巧：泵压力正常、阀后压力不足、保持时压力下降快 → 执行元件（油缸）内泄。

## Q10：发动机空转正常、带负荷无力发闷易熄火？

**答**：多为燃油供给系统问题。案例 1：滤芯至输油泵之间油管内胶皮老化、空心螺栓内小滤网堵塞 → 供油节流，换油管+清洗螺丝恢复。案例 2：挖土冒黑烟无力，排气积炭多+空滤真空指示器红色，换滤芯无效 → 顺进气道查出粗滤网被柳絮堵死，清理恢复。

## Q11：发动机过热（水温高）怎么查？

**答**：分"发热过度"与"散热不足"两类：
- 发热过度：正时不良着火过迟、燃烧室窜机油、喷柴油过量、长时间超负荷；
- 散热不足：缺水、水质差结垢、节温器大循环开度不够、水箱格栅堵塞、水泵不良、风扇皮带松弛、叶片变形。
典型案例：水箱与液压油散热器之间被柳絮堵塞（发动机向里抽风，外观只看到油散），拆开海绵清理后恢复。清洗水箱/油冷、调整皮带张紧是基础动作。

## Q12：排气管冒黑烟的原因？

**答**：黑烟=燃油不完全燃烧的碳粒。原因：高压油泵供油量过大或各缸不均匀；气门密封不严漏气、缸压低；空滤/进气道阻塞；缸套活塞活塞环严重磨损；喷油器雾化不良；超负荷运转；供油提前角过小。

## Q13：挖掘机冬季启动困难？

**答**：多因素叠加——柴油结蜡堵油路、压缩温度不足难压燃、电瓶亏电马达无力、机油过稠阻力大、气门间隙/供油时间/喷油雾化不良。分三种情况：
1. 排气不冒烟=柴油结蜡堵油路 → 加装燃油预热器（首选）；
2. 冒烟不爆燃=缸温低、雾化差 → 电瓶良好可连续启动；启动液是最后手段（易依赖）；
3. 转速不够 → 机油过稠换冬季机油；电压 >24V 问题在马达（换碳刷），<24V 先充电/搭电。

## Q14：卡特挖机难启动，是不是电瓶问题？

**答**：不一定。起动机转速正常却"干打雷不下雨"就要查燃油系统和转速传感器。真实案例（CAT 324D）：
1. 读码得 P0087（轨压过低）→ 锁定油路；
2. 换燃油滤芯（发现副厂件有杂质）无效；
3. 拔 SCV 阀插头强制油泵全负荷 → 一把着火，锁定 SCV 阀/喷油器；
4. 喷油器回油量测试：6 支喷油器回油量远超标准 → 喷油器磨损回油过大。
结论：卡特/小松电喷机 8000-10000 小时后喷油器磨损是"老年病"。核心原因汇总：电瓶/起动机、油路进空气、SCV 阀故障（P0087/P0093）、喷油器磨损、曲轴/转速传感器。

## Q15：凯斯 490 启动困难+干活冒黑烟+一干活就掉怠速？

**答**：综合指向燃油供给与动力匹配。排查顺序：①喷油器（磨损/雾化差/内泄致启动轨压不足，上校泵台检测）；②高压油泵与轨压（负载增加供油跟不上，轨压大跌触发保护性降速，查柱塞磨损、计量比例阀卡滞）；③进气系统与增压器；④液压泵控制系统（主泵调节器/比例电磁阀卡滞导致吸收扭矩过大憋车）；⑤低压油路（滤芯、进空气、油箱杂质水分）。

## Q16：液压故障排查的总流程（新手版）？

**答**：先"感官五查"——问（何时开始、冷机/热机、是否换过油）、看（油位、乳化/发黑、回油滤金属屑）、听（泵异响、溢流阀嘶嘶声）、摸（温度异常）、测（主压力/先导压力/工作腔压力）。核心参数：压力、流量、温度。排查顺序：
1. 查油位油质 → 2. 查吸油管路（滤芯堵塞、漏气涂肥皂水）→ 3. 查油泵（出口压力低且调溢流阀无效=泵内泄）→ 4. 查溢流阀（清洗阀芯重新调定）→ 5. 查控制阀（测各工作口压力判断阀芯卡滞/弹簧断）→ 6. 查执行元件（保持压降快=油缸/马达内漏）。
口诀：一查油位油质，二查吸油管路，三查泵压是否足，四调溢流阀，五测阀口压，六查油缸漏。
新手三大忌：不做压力测试就拆阀；忽视液压油清洁度；只修不查根因（如溢流阀卡滞根源是油脏，不换油会复发）。

## Q17：挖掘无力但发动机正常（单斗挖掘机液压系统）？

**答**：按类型查：
- 液压泵故障：柱塞/配油盘划伤磨损、吸油不足（吸油管堵塞、滤芯脏）、泵转速不足 → 清洗/换滤芯、检查吸油管密封、测泵出口压力对比原厂值、磨损严重换泵；
- 溢流阀/安全阀失效：阀芯卡滞、弹簧疲劳 → 拆阀组柴油清洗、校准溢流压力至标准值；
- 液压油不足或污染：油位低吸空、乳化变质 → 补同型号油；污染则换油+清洗油箱管路（建议 2000-3000h 换油）。

## Q18：回转/行走无力？

**答**：马达内部磨损（配流盘、轴承）容积效率下降 → 测进出口压差，严重换马达或大修；行走制动阀故障制动片未完全松开 → 查制动油路压力、清洗制动阀组。

## Q19：EX200-5 挖掘无力相关标准数据？

**答**：主安全阀标准压力 320kg，实测仅 230kg 即导致挖掘无力；阀杆与阀孔磨损间隙过大、回位不完全导致流量不足。先导齿轮泵磨损或其安全阀压力不够 → 泵始终低流量、阀杆换向不完全。处理：多路阀上试验台重设安全阀压力、消间隙；换先导齿轮泵或重设先导安全阀。

## Q20：液压油温超过多少算异常？

**答**：油温超过 80℃ 即加速密封老化、油液粘度下降、内泄加剧，应视为异常（徐工报警阈值 90℃）。常见原因：散热器堵塞、溢流阀频繁溢流、油牌号不对、内泄。
