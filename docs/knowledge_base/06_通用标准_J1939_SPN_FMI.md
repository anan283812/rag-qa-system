## 一、体系说明

SAE J1939 是重机（CAT、John Deere、Cummins、Volvo、三一、徐工等）通用诊断标准。ECU 通过 CAN 总线报告故障，格式为 **SPN + FMI**：
- **SPN**（Suspect Parameter Number，可疑参数号）：哪个部件
- **FMI**（Failure Mode Identifier，故障模式标识符）：什么类型的故障

## 二、FMI 通用语义（全品牌通用）

| FMI | 含义 |
|---|---|
| 0 | 数据有效但高于正常范围（最严重档） |
| 1 | 数据有效但低于正常范围（最严重档） |
| 2 | 数据不稳定、间歇或不正确 |
| 3 | 电压高于正常值或对电源(+Batt)短路 |
| 4 | 电压低于正常值或对地短路 |
| 5 | 电流低于正常值或断路 |
| 6 | 电流高于正常值或对地短路 |
| 7 | 机械系统响应不正常（部件卡滞/不动作） |
| 8 | 信号频率/脉冲宽度/周期异常 |
| 9 | 通信异常更新率 |
| 10 | 异常变化率 |
| 11 | 故障模式无法识别 |
| 12 | 部件/设备损坏 |
| 13 | 校准失败 |
| 14-17 | 特殊/超温/超压告警档（不同系统定义略异） |
| 31 | 一般告警（no available） |

## 四、高频 J1939 故障码与处理

### 排放与后处理（Tier 4 / 国四）
- **SPN 3226（NOx 传感器）**：读数错误或内部故障 → 发动机降额。先查线束与接头，紧固后仍报警则换 NOx 传感器（寿命件，常因高温失效）。
- **SPN 4364（SCR 转化效率）**：严重降功率。检查 DEF 喷射器是否白色结晶；喷射器干净则可能为出口 NOx 传感器数据漂移，需更换。
- **SPN 3364（DEF 质量）**：DEF 被稀释或不纯 → 跛行模式。排空重新加注合格 DEF；仍报警则换 DEF 质量传感器（一般集成在储罐集箱）。

### 关键发动机传感器
- **SPN 100（机油压力）**：过低，非常危险。立即停机查油位；油位正常则查压力传感器电路。
- **SPN 110（水温）**：过热或传感器误报。查冷却液位、散热器杂物；发动机实际不热则换水温传感器。
- **SPN 102（增压压力）**：涡轮未达到预期增压。查进气软管、中冷器泄漏；管路正常则疑 MAP 传感器。
- **SPN 94（燃油输送压力）**：低压系统不达标。先换柴油滤芯，无效查输油泵/燃油压力传感器。
- **SPN 97（燃油含水）**：立即排放油水分离器积水；排水后灯不灭则查传感器/更换滤杯。

## 五、SPN 100 FMI 1（低油压）深度排查流程

发生机理：ECM 检测到油压低于当前工况最小阈值 → 停机/检查灯亮 → 功率降额 → 可能自动熄火保护。

### A. 真实低油压原因
1. 油位低（坡道/颠簸时吸油口露出）；
2. 粘度不合适（高温热怠速压力保持不住）；
3. 油被燃油稀释/进冷却液/超期劣化；
4. 机油滤清器堵塞、旁通阀卡滞；
5. 吸油管密封件/O 型圈吸气（油中气泡 → 间歇性低码，低转速易现）；
6. 机油泵磨损/泄压阀卡在开位；
7. 发动机内部磨损（轴承间隙大，伴随异响、油中金属屑）。

### B. 假信号原因
1. 压力传感器故障/漂移；
2. 接头松动、腐蚀、油侵、针脚弯曲；
3. 线束磨损、对地短路、信号/回路高电阻；
4. 接地不良或电源基准问题；
5. 校准/软件不匹配（少见，刷写后可能出现）。

### C. 排查步骤
1. 记录冻结帧：小时数、油温、发生时转速、工况（热怠速/坡道/负载变化/保养后）；
2. 平地冷机 5 分钟后查油位与油质（稀、燃油味、乳化）；
3. 机械压力表实测主油道压力对比 ECM 读数（判断真低还是假低）；
4. 真低 → 严禁继续运转，按 A 项逐项排查；假低 → 查传感器 5V 供电、信号电压、接地电阻；
5. 间歇性事件重点：热怠速压力临界、吸气泄漏、传感器/线束接触不良。

## 六、识别与读码工具

- 监控器服务菜单（多数现代机型可直接读 Active/Logged 码）；
- 各家专用软件：CAT ET（Communication Adapter III）、Komatsu KOMTRAX、Doosan DMS-5、Hitachi Dr.ZX、Volvo VCADS/Tech Tool、XCMG DMS；
- 通用 J1939 适配器（CAN 读码器）可跨品牌读 SPN/FMI。
