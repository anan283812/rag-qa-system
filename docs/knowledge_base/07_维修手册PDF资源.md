## 一、手册类型说明

1. **Service Repair Manual（维修手册）**：发动机大修、液压系统维修、电路图、诊断步骤、扭矩标准 —— 面向维修技师。
2. **Parts Manual / Parts Catalog（配件目录）**：爆炸图、件号、装配分解 —— 面向配件商。
3. **Operation & Maintenance Manual（O&M，操作保养手册）**：日检清单、保养周期、安全操作、润滑燃油规范 —— 面向机手/现场主管。

## 三、中文图书资源（维修精华丛书，机械工业出版社等）

- 《挖掘机维修标准速查手册》张凤山主编（2012）：汇编小松、日立、大宇、神钢、加藤、沃尔沃维修标准与技术参数（扭矩、压力、间隙、装配检测标准，全表格/插图）。目录含：小松 PC200-5 / PC300-5 / PC400-5 / PC200LC-5 / PC220-5 / PC60-6 / PC240-5 / PC60-7 / PC200-7 等机型传动/液压/工作装置维修标准。资源页：bzfxw.com（8.07MB PDF）。
- 《日立挖掘机维修手册（上册）》张凤山、静永臣主编（2010，ISBN 9787111289258）：日立 ZAXIS70/70LC、ZAXIS130、EX200-7 结构原理、拆装、故障诊断（Dr.EX 操作、A/E 模式故障诊断、ICX 信息控制器故障码）。预览：tushu007.com。
- 同丛书还包括《小松挖掘机维修手册（上/下）》《大宇现代挖掘机维修手册》《住友挖掘机维修手册》《神钢挖掘机维修手册》。

## 四、英文综合手册站

- **manualkarts.com**：按品牌分类（CAT / Komatsu / Hitachi / Volvo / Hyundai / JCB / Kobelco / Case / Takeuchi），提供 Service/Parts/O&M 三类 PDF，按型号检索。
- **pdfmanual4trucks.com**：多品牌手册与故障码 PDF 直链。
- **manuals-free.com**：斗山 DTC 表等免费 PDF。
- **indexof.sellfy.store**：Hitachi Zaxis 200/225/230/270 Technical Troubleshooting Manual（KM-178E，404 页，收费）——内容含性能测试标准、Dr.ZX 故障码清单、故障诊断 A、元件布置、电气系统等目录结构可参考。
