## 一、徐工（XCMG）故障码体系

### 编码规则（源自官方《报警故障信息 V1.1》）
- 4 位码 `E1200 0` 示例：最后一位为故障模式：1=线路短路/过电流，2=线路断路/电流不足，3=低/低量程，4=高/超高量程，5=其它；中间 1-99 为故障器件编号；千位类别：0=GPS 故障，1=液压故障，2=电磁阀故障，3=发动机相关，4=控制器故障，5=其他电气故障。
- A = 报警信息（仪表显示报警图标）；E = 故障信息（存储统计）。

### XE750D 262-4 SPN3509 FMI4 示例
- 含义：传感器电源 1 电压低于正常值（SPN3509 主泵压力传感器，FMI4 电压低）。
- 症状：液压系统故障灯、重载无力、动作迟缓、降功率。
- 排查：XCMG DMS 读数据流（正常 0.5-4.5V）→ 查线束磨损/断路/接头腐蚀 → 测传感器供电 5V → 测电阻对比标准值 → 换传感器或检修 ECM。

## 三、通用提示

- 国产品牌（三一/徐工）仪表报警多与传感器电路四态相关：故障/短路/断路/低量程/高量程，与 J1939 FMI 语义一致，可映射处理。
- 降功率（Derate）在国产机型同样存在：水温/油温超高、传感器失效、扭矩限制激活都会触发。
